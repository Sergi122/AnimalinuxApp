Editor de píxeles

Estilo Aseprite: capas, línea de tiempo, pixel-perfect, tintas, simetría, modo mosaico, lazo y varita, con los mismos atajos.

Editor de animación

Estilo Toon Boom Harmony: capas raster y vectoriales, hoja de exposición, papel cebolla, mesa de luz, cámara animada, 12 pinceles y exportar GIF/MP4.

Overlay transparente

Una ventana por mascota con física real y 8 poses: idle, walk, greet, kiss, jump, angry, grab y fall.

Modos

Dos modos, una mascota.

Elige cómo la quieres en tu escritorio: quieta o con vida propia.

🧬 Con vida

Camina sola, salta, saluda, se enoja, duerme, trepa por ventanas y reacciona al cursor, con varias poses.

🖼 Sin vida

Un GIF en bucle flotando en el escritorio. Ideal para un icono animado quieto, sin física ni comportamiento.

Instalación

Listo en un minuto.

Elige tu distribución.

bash
# Opción recomendada, AUR
$ paru -S animalinux
# o compilando tú mismo
$ git clone https://github.com/Sergi122/AnimalinuxApp.git && cd AnimalinuxApp
$ makepkg -si
$ sudo apt install python3 python3-gi gir1.2-gtk-4.0 python3-pip python3-pil \
                  gir1.2-ayatanaappindicator3-0.1 gir1.2-wnck-3.0

$ git clone https://github.com/Sergi122/AnimalinuxApp.git
$ cd AnimalinuxApp
$ pip install --user --break-system-packages .
$ animalinux --show
# Fedora
$ sudo dnf install python3 python3-gobject gtk4 python3-pillow \
                  libappindicator-gtk3 libwnck3

# openSUSE
$ sudo zypper install python3 python3-gobject gtk4 python3-Pillow libwnck3

$ git clone https://github.com/Sergi122/AnimalinuxApp.git
$ cd AnimalinuxApp
$ pip install --user --break-system-packages .
$ animalinux --show

gtk4-layer-shell solo hace falta en Hyprland/Sway. En GNOME, Cinnamon, MATE y Xfce la app usa su propio backend X11; libwnck es opcional.
